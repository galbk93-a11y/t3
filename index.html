חקירת פונקציה – שורש במכנה ופרמטר

כיתה י"א, 5 יחידות לימוד · חור, אסימפטוטה אנכית וקיצון

התרגיל

נתונה הפונקציה (כאשר a > 0 פרמטר):

f(x)=x2x−ax

ידוע שלגרף הפונקציה יש אסימפטוטה אנכית ב-x = 4.

  1. מצאו את a. בהמשך התרגיל הציבו את הערך שמצאתם.
  2. מצאו את תחום ההגדרה של הפונקציה.
  3. מצאו את הנקודה שבה יש "חור" בגרף הפונקציה. מהן קואורדינטותיה?
  4. מצאו את האסימפטוטות האנכיות, וחקרו את התנהגות הפונקציה כאשר x → ∞.
  5. מצאו את נקודות החיתוך עם הצירים ואת תחומי החיוביות והשליליות.
  6. גזרו את הפונקציה, ומצאו תחומי עלייה וירידה ונקודות קיצון.
  7. סרטטו סקיצה של גרף הפונקציה, תוך סימון החור, האסימפטוטה והקיצון.
  8. (אתגר) לכמה פתרונות יש המשוואה f(x) = k בהתאם לערך k?

פתרון מלא

א. מציאת a
המכנה: x − a√x = √x(√x − a), והוא מתאפס ב-x = 0 וב-x = a².
ב-x = a² המונה a⁴ ≠ 0, ולכן שם אסימפטוטה אנכית. מהנתון a² = 4, ומכיוון ש-a > 0:
a = 2, כלומר f(x) = x² / (x − 2√x).
ב. תחום הגדרה
תנאי השורש: x ≥ 0. תנאי המכנה: √x(√x − 2) ≠ 0 ⇒ x ≠ 0, x ≠ 4.
תחום: (0, 4) ∪ (4, ∞).
ג. מציאת החור בעזרת הצבות
נבדוק את הנקודות שבהן המכנה מתאפס: x = 0 ו-x = 4.
x = 4: הצבה במונה נותנת 4² = 16 ≠ 0 והמכנה מתאפס, כלומר 16/0. זה מצביע על אסימפטוטה ולא על חור.
x = 0: הצבה נותנת 0/0, ולכן ייתכן חור. נבדוק מה קורה לפונקציה כשמתקרבים ל-0 (מימין בלבד, כי משמאל היא לא מוגדרת), על ידי הצבת ערכים קרובים:
x√xf(x)

ככל ש-x מתקרב ל-0, הערכים f(x) מתקרבים ל-0.
הגבול ב-x = 0 הוא 0, והפונקציה לא מוגדרת שם, ולכן יש חור בראשית הצירים (0, 0).
ד. אסימפטוטות והתנהגות באינסוף
אנכית: ב-x = 4 המונה 16 ≠ 0 והמכנה מתאפס (כפי שמצאנו בסעיף ג). כדי לקבוע את הסימן נפרק את המכנה: x − 2√x = √x(√x − 2).
x → 4⁻: √x − 2 → 0⁻, ולכן f → 16/0⁻ = −∞ · x → 4⁺: f → 16/0⁺ = +∞
אסימפטוטה אנכית: x = 4 (משני הצדדים).
באינסוף: f(x)/x = x/(x − 2√x) → 1, כלומר f(x) ≈ x → ∞, ולכן אין אסימפטוטה אופקית.
בדיקת אסימפטוטה משופעת: f(x) − x = 2x√x/(x − 2√x), ובחלוקה ב-x מתקבל 2√x/(1 − 2/√x) → ∞. הפער גדל, ולכן גם אין אסימפטוטה משופעת.
ה. חיתוכים וסימן
ציר y: x = 0 לא בתחום (זה החור). ציר x: המונה x² = 0 רק ב-x = 0, שגם הוא החור.
המונה x² > 0 בתחום, והמכנה √x(√x − 2) נקבע לפי √x − 2:
f < 0 עבור 0 < x < 4 · f > 0 עבור x > 4 · אין חיתוכים עם הצירים.
ו. נגזרת וקיצון
גוזרים בכלל המנה את f(x) = x² / (x − 2√x). נגזרת המכנה: 1 − 1/√x.
f′(x)=2x(x−2x)−x2(1−1x)(x−2x)2=x2−3xx(x−2x)2
מפרקים: המונה x√x(√x − 3) והמכנה x(√x − 2)², ולכן f′(x) = √x(√x − 3)/(√x − 2)².
המכנה חיובי, והסימן נקבע לפי √x − 3. הנגזרת מתאפסת ב-x = 9.
יורדת ב-(0, 4) וב-(4, 9) · עולה ב-(9, ∞) · מינימום ב-(9, 27).
(חישוב: f(9) = 81/(9 − 6) = 27.)
ז. סקיצת הגרף
ענף שמאלי: יוצא מהחור (0, 0), יורד דרך (1, −1) ו-(3, −19.4), וצולל ל-−∞ ליד x=4.
ענף ימני: יורד מ-+∞ ליד x=4 עד המינימום (9, 27), ואז עולה לאינסוף.
הגרף מצויר מהנוסחה עצמה:
קו כחול: הפונקציה · מקווקו: האסימפטוטה x=4 · עיגול ריק: החור (0, 0) · נקודה: המינימום (9, 27) · קו צהוב: y = k (סעיף ח)
ח. פתרון f(x) = k
בענף השמאלי הפונקציה יורדת מ-0 ל-−∞ (הערך 0 לא מתקבל, כי הוא החור). בענף הימני היא יורדת מ-∞ ל-27 ואז עולה בחזרה ל-∞.
k < 0: פתרון אחד · 0 ≤ k < 27: אין פתרון · k = 27: פתרון אחד (x = 9) · k > 27: שני פתרונות.
